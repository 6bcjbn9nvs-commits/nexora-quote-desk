# Nexora Quote Desk — 웹 버전

인테리어·시공 업체용 견적 도구 **Nexora Quote Desk v2.0**을 브라우저에서 바로 쓸 수 있도록 올려 둔 정적 사이트입니다. GitHub Pages로 서비스됩니다.

- 사이트: https://6bcjbn9nvs-commits.github.io/nexora-quote-desk/

## 구성

| 경로 | 내용 | 접근 |
|---|---|---|
| `/` | 허브 랜딩 (한국어 / English) | 공개 |
| `/lite-ko/` | Nexora Quote Desk **Lite** 한국어판 | 공개 |
| `/lite-en/` | Nexora Quote Desk **Lite** 영문판 | 공개 |
| `/kit-ko/` | Nexora Business **Kit** 한국어판 | 구매자 액세스 코드 |
| `/kit-en/` | Nexora Business **Kit** 영문판 | 구매자 액세스 코드 |

각 앱은 **단일 HTML 파일**이며 외부 리소스나 네트워크 요청이 없습니다. 입력한 견적은 서버로 전송되지 않고 사용자의 브라우저 저장소에만 남습니다.

## 액세스 코드

유료 제품(Business Kit) 페이지는 첫 화면에서 액세스 코드를 확인합니다. 코드는 구매 완료 메일·전달 메시지와 함께 구매자에게만 안내되며, 이 저장소에는 기재하지 않습니다. 코드는 소스에 평문으로 두지 않고 해시로만 비교합니다.

## 이 저장소에 없는 것

- Pro·Kit 원본 배포 파일(ZIP)과 프리셋·문자 스크립트 등 부가 자료
- 구매자 데이터, 주문 정보
